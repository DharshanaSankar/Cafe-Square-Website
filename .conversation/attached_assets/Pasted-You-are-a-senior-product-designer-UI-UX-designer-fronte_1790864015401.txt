4. UX PSYCHOLOGY
==================================================

Use ETHICAL behavioral design principles to improve usability and conversion.

Do not manipulate or deceive users.

Apply:

A. VISUAL HIERARCHY

The most important information should be immediately visible:

Cafe Square
↓
What the cafe offers
↓
Food imagery
↓
Explore Menu
↓
Order / Visit
↓
Location

Use size, spacing, contrast and position to guide attention.

B. FAMILIARITY

Use familiar UI patterns.

Users should immediately understand:
- Menu
- Order
- Call
- Directions
- Cart
- Contact

Do not make users learn unusual interactions.

C. VISUAL APPETITE

Food photography should be one of the strongest visual elements.

Use:
- Large food images
- Close-up crops
- Warm lighting
- Strong contrast
- Clean backgrounds
- Generous whitespace

Use image placeholders if actual images are unavailable.

Make it extremely easy for the owner to replace placeholder images later.

D. FRICTION REDUCTION

Reduce the number of steps required to:

Call
Order
Find location
View menu

Examples:

"Call Now"
"Order Now"
"Get Directions"

should be immediately accessible.

E. CTA HIERARCHY

Primary CTA:
Order Now

Secondary CTA:
Explore Menu

Tertiary:
Get Directions
Call Cafe

Do not make every button visually equal.

F. SOCIAL PROOF

If verified customer reviews become available, create a dedicated review section.

Until verified reviews are supplied:
DO NOT fabricate them.

G. SCARCITY

Never create fake scarcity.

Only show:
- Limited-time offers
- Today's specials
- Limited items

if the owner provides real information.

H. RECIPROCITY / VALUE

Make the site useful before asking users to order.

Let visitors:
- Browse menu
- Discover popular items
- Find location
- Check hours
- See food
- Understand the cafe

I. COGNITIVE LOAD

Avoid overwhelming users.

Use:
- Clear categories
- Progressive disclosure
- Short descriptions
- Visual grouping
- Consistent layouts
